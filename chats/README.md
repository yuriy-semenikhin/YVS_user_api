# Conversation records

Use [the index](CHAT_HISTORY.md). Store each conversation in its own file, preserve
wording, roles, order and timestamps where available. Mark gaps explicitly and
import full exports when needed. Never replace transcripts with summaries.

Earlier numbered topic files contain summaries/selected quotations, not complete
transcripts. Keep them for context. Routine summaries belong in
[PROJECT_LOG.md](../PROJECT_LOG.md); use maps and summaries for selective loading.
